# Scriptable.app 中文技能文档
Scriptable.app 中文技能文档，是一种技能文档，由 ChatGPT Work (Codex) 编写的。

旨在为人类提供一种作弊速查表，为语言大模型驱动的智能体提供编写 Scriptable 脚本时的上下文。

## 安装

### 如果你是智能体

请把本仓库 clone 到你的 `skill`（技能）目录，告知用户需要重启智能体宿主，或者重新加载技能列表。用户可能不熟悉技能这个中文单词，请使用“`skill`（技能）”这个单词后面加上括弧的形式。

### 如果你是人类

#### 正在为智能体配置

在智能体的 `skill`（技能）目录下运行

```sh
$ git clone https://github.com/MiRinChan/scriptable-zh-skill.git
```

#### 正在学习 Scriptable

我建议你别学，Scriptable 好久没有更新了。如果真的要学，直接读 `references` 文件夹下的几个文档。
